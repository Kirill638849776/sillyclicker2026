# 🐾 sillyclicker2026

Простой и забавный кликер, созданный на Godot Engine 4.7.  
Цель игры — нажать кнопку 100 раз… но финал тебя удивит.

## 🎮 Особенности
- Счётчик кликов на экране  
- Кнопка, увеличивающая счётчик  
- Финальный экран с красным фоном  
- Сообщение **«Твоё время вышло»**  
- Фирменный писк **«поиск»** три раза  
- Автоматическое закрытие игры после финала  
- Работает как отдельный `.exe` файл

## 🧩 Технологии
- **Godot Engine 4.7.2**
- GDScript
